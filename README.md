# Step-Wise Refusal Dynamics: project page

Static GitHub Pages site for *Step-Wise Refusal Dynamics in Autoregressive and Diffusion Language Models* (Rahimi, Hirshel, Himelstein, LeVi, Mendelson, Baskin; EMNLP 2026; [arXiv:2602.02600](https://arxiv.org/abs/2602.02600)).

Live site: https://gabrieleserussi.github.io/sri-project-page/ (repository `GabrieleSerussi/sri-project-page`, classic version).

## Two versions, one content

| File | Look | Use |
| --- | --- | --- |
| `index.html` | Decart Research design: Roobert and Season, paper texture, Decart nav, footer and navy banner | Decart-branded publication |
| `classic.html` | Traditional project page: centered header with institution logos and the cover beneath it, Inter and Source Serif 4, white background, light panels, plain footer | The version currently deployed |

Both share every section, chart and script. `classic.html` is generated from `index.html` by `make_classic.py`, so edit `index.html` and regenerate; never edit `classic.html` by hand.

## Update and publish

1. Edit `index.html` (or the CSS and JS), then rebuild: `python3 configure.py --url https://gabrieleserussi.github.io/sri-project-page/ --repo GabrieleSerussi/sri-project-page`. This regenerates `classic.html` and both zips. `python3 make_classic.py` alone regenerates only `classic.html`.
2. Unzip `sri-page-classic.zip` and copy it over the repository folder, then push:
   ```bash
   rsync -a --delete --exclude .git ~/Downloads/sri-page-classic/ /path/to/repo/
   cd /path/to/repo && git add -A && git commit -m "Update page" && git push
   ```
   The remote uses HTTPS (`https://github.com/GabrieleSerussi/sri-project-page.git`); GitHub asks for a personal access token as the password the first time.
3. GitHub Pages redeploys within a minute (repository Settings, Pages: branch `main`, folder `/ (root)`).

### Custom domain

1. Run `configure.py` with the domain, for example `--url https://sri.example.org/`. It rewrites the absolute URLs (`og:image`, `og:url`, canonical), the Colab links in both pages, the notebook and its README, and writes `CNAME`.
2. Push as above.
3. DNS: for a subdomain such as `sri.example.org`, a CNAME record to `gabrieleserussi.github.io`; for an apex domain, A records to 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
4. Repository Settings, Pages, Custom domain: enter the host, wait for the DNS check, tick "Enforce HTTPS".

## Behaviour worth knowing

- **Colab button.** After `configure.py` the link points at `https://colab.research.google.com/github/GabrieleSerussi/sri-project-page/blob/main/colab/sri_playground.ipynb`; the repository must stay public. Before configuration the script in `js/main.js` derives the link from a `github.io` host and otherwise falls back to downloading the notebook.
- **Phones (up to 700px).** The lede shows its first two sentences, each act shows its lead paragraph, one visual and the takeaway, and a "Read the full section" button reveals the rest (blocks marked `class="deep"` in `index.html`). A sticky jump bar lists the five acts on tablets and phones.
- **URL flags.** `?static=1` disables the reveal-on-scroll animation (screenshots, print); `?mode=ar` opens the cover on the autoregressive tab.
- **Structure.** Header with the interactive cover, a three-beat summary and four stat cards, five acts (`#recovery`, `#sampler`, `#sri`, `#guard`, `#build`), the Discussion quote, BibTeX and contacts, the Decart or affiliations banner, footer. Nav and quick links point at these ids.

## Content and sources

- Every number is taken from the paper's tables and figures and was audited twice against the paper text. Chart data lives at the top of each block in `js/main.js` (`hrr`, `delta`, `gap`, `ablation`, `defenses`); the explorer notes are in `INFO`. The four "What you learn" callouts and the closing quote are verbatim from the paper.
- The cover is a schematic of the mechanism (Sections 2.2 and 3, Figures 1, 2 and 12) and says so; `assets/data/sri-real.json` holds curves digitized from Figure 2 and Figure 12 for anyone who wants measured trajectories.
- BibTeX is the official arXiv export. Emails: elironrahimi@campus.technion.ac.il (corresponding author) and chaimbaskin@bgu.ac.il.
- Affiliations follow the paper's first page; "Decart.ai, Israel" is added for Chaim Baskin.
- Author links: Eliron Rahimi (OpenReview), Rom Himelstein and Amit LeVi (Google Scholar), Avi Mendelson (Technion page), Chaim Baskin (BGU page). Elad Hirshel has no personal page.
- Fonts: Roobert and Season are self-hosted for the Decart version (licence confirmed on 2 September 2026); the classic version loads Inter and Source Serif 4 from Google Fonts.
- Logos in the classic header: Technion (university logo), Ben-Gurion University and University of Haifa (Wikimedia Commons, public domain), INSIGHT Lab (from the lab's own PDF), Decart (Decart Research). Each links to the department, lab or research page.
- House style for the copy: complete calm sentences, no em or en dashes, ranges written as "48 to 62%", every claim traceable to the paper.
